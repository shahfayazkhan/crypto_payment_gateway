# CryptoGate frontend

Next.js 16 (App Router) + MUI 9. Client portal (`/client`) and back office (`/admin`), updated live over Socket.IO.

```bash
cp .env.local.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:4000
npm install
npm run dev
```

See the root README for the full setup and realtime testing guide.
